GameReel — политика конфиденциальности

Действует с 24 октября 2026 года · English

GameReel — генератор игровых идей. Разработчик: Restor-0o0 (github.com/Restor-0o0/GameReel).

Какие данные обрабатываются

Приложение хранит сохранённые идеи, заметки, пресеты, импортированные библиотеки и настройки только на вашем устройстве или в хранилище браузера. Учётная запись не нужна. Разработчик не получает эти данные: в приложении нет собственного сервера, аналитики, рекламы и сторонних SDK для сбора данных.

Кроме описанного ниже предложения пакетов, приложение выходит в интернет только за каталогом игровых пакетов и их картинками: файлы пакетов скачиваются с GitHub, картинки — с серверов издателей игр (Steam, Riot Games, valorant-api.com, PUBG). В этих запросах нет личных данных; серверы видят только обычные сведения о запросе, например IP-адрес. Картинки кешируются на устройстве. Импорт читает только файл, который вы выбрали в системном диалоге.

Предложение пакетов в каталог

В редакторе игровых пакетов есть кнопка «Предложить в каталог». Только по её нажатию пакет (названия, категории, варианты, ссылки на картинки) и необязательный комментарий отправляются разработчику через Google Apps Script и публикуются как открытый pull request в репозитории на GitHub. Учётная запись и личные данные не нужны; не пишите их в комментарий. Google и GitHub видят обычные сведения о запросе, например IP-адрес. Чтобы удалить отправленный пакет, напишите в GitHub Issues или на почту разработчика из карточки в Google Play.

Ссылки на идеи

Кнопка «Копировать ссылку» кодирует выбранные теги и название идеи прямо в адрес ссылки. Ссылка нигде не сохраняется, пока вы сами её не отправите. Получатель видит то же сочетание. Не добавляйте в название личные данные.

Резервные копии

Android может включать данные приложения в системные резервные копии, если это разрешено в настройках устройства. Их обработку регулирует поставщик резервного копирования.

Внешние сайты

Ссылки на магазины и страницы игр открываются в браузере. На этих сайтах действуют их собственные политики. Веб-версия размещена на GitHub Pages. GitHub может вести обычные журналы HTTP-запросов, см. GitHub Privacy Statement.

Удаление данных

Идеи и пресеты удаляются в приложении. Все данные Android-версии удаляются через «Настройки → Приложения → GameReel → Хранилище → Очистить данные» или вместе с приложением. Данные веб-версии удаляются очисткой данных сайта в браузере.

Дети

Приложение не предназначено специально для детей и не собирает личные данные пользователей любого возраста.

Изменения и контакты

Если в приложении появится сбор или передача данных, эта страница будет обновлена до выхода версии. Вопросы можно задать через GitHub Issues.

GameReel Privacy Policy

Effective October 24, 2026

GameReel is a game idea generator by Restor-0o0 (github.com/Restor-0o0/GameReel).

Data

Saved ideas, notes, presets, imported libraries and settings stay on your device or in your browser storage. No account is required. The developer does not receive this data: the app has no backend, analytics, advertising or third-party data collection SDKs.

Apart from suggesting packs (see below), the app goes online only for the game pack catalog and pack pictures: pack files come from GitHub, pictures from the game publishers’ servers (Steam, Riot Games, valorant-api.com, PUBG). These requests carry no personal data; the servers see ordinary request details such as your IP address. Pictures are cached on the device. Import reads only the file you pick in the system dialog.

Suggesting packs for the catalog

The game pack editor has a “Suggest for catalog” button. Only when you tap it, the pack (names, categories, options, picture links) and your optional comment are sent to the developer through Google Apps Script and published as a public pull request in the GitHub repository. No account or personal data is needed; do not put any in the comment. Google and GitHub see ordinary request details such as your IP address. To have a submitted pack removed, write in GitHub Issues or to the developer email shown on Google Play.

Idea links

“Copy link” encodes the selected tags and the idea title in the link itself. Nothing is stored until you share the link yourself. Do not put personal information in the title.

Backups

Android may include app data in system backups if your device settings allow it. The backup provider’s terms apply.

External sites

Store and game links open in your browser under the destination site’s policy. The web version is hosted on GitHub Pages, which may keep ordinary HTTP request logs, see the GitHub Privacy Statement.

Deleting data

Delete ideas and presets in the app. Clear all Android data in Settings → Apps → GameReel → Storage → Clear data, or uninstall the app. Clear site data in your browser for the web version.

Children

The app is not directed at children and does not collect personal data from users of any age.

Changes and contact

If the app ever starts collecting or sharing data, this page will be updated before that release. Contact: GitHub Issues.
