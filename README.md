# GameReel

Локальный генератор игровых идей на Kotlin Multiplatform: восемь барабанов, слот-машина,
Spin / Freeze / Pin, история и сохранённые идеи. Анимацию можно отключить.
В меню `⋮` пункт «Сбросить барабаны» возвращает исходный набор; стрелка ↶ отменяет сброс.

Встроены три библиотеки по 1000 игр: Steam Broad, Steam All-Time и Google Play.
Дополнительно доступна `itch.io · Selected`: 28 игр и 120 тегов по страницам авторов,
без копирования обложек. Источники и дата проверки — в `tools/library_sources/itch_selected/provenance.json`.
Библиотека «Теги GameReel» v10 содержит 1461 тег в 18 категориях,
включая мир/эпоху, локацию, окружение и твисты. Эти теги не приписываются играм.
Описания, теги игр и игры-референсы (до трёх на тег) проверены вручную, правки лежат в
`tools/library_sources/review`.
В автомате и карточках вместо эмодзи показывается картинка игры, из которой выпал тег; для тегов «Теги GameReel» —
самой популярной игры-референса. Картинки лежат в ресурсах (`files/art`), сеть не нужна; если картинки нет, остаётся эмодзи.
В интерфейсе теги показываются под короткими именами из `ui/presentation/TagShortNames.kt`, исходное имя видно в карточке и поиске.
Кнопка «Объединить все библиотеки» включает общий пул, включая импортированные наборы.

## От сочетания к проекту

Сохранённую идею можно развить: заполнить краткую концепцию, основной игровой цикл,
цель игрока и отличительную фишку. Идеи группируются по имени проекта. Из сохранённой
идеи можно начать вариант: барабаны загрузятся, после изменений и сохранения новая идея
получит связь с оригиналом; варианты сравниваются на экране идей. Режимы над барабанами
ограничивают выбор тегов при следующей прокрутке (соло, джем, мобильная игра, офлайн).
Это ориентиры по масштабу, а не автоматическая оценка выполнимости.
Над барабанами можно создать собственный фильтр: выбрать базовый режим, исключить слова
из названий тегов и при необходимости закрепить источники. Фильтры сохраняются,
редактируются и переключаются там же; выбранный набор тегов они не заменяют.

Карточку идеи можно скопировать, сохранить как текст или SVG-изображение. В настройках
есть JSON-бэкап рабочего пространства: идеи, проекты, пресеты, параметры и пользовательские
библиотеки. Встроенные библиотеки поставляются приложением и не дублируются в бэкапе.
Восстановление заменяет текущее рабочее пространство после подтверждения, но не удаляет
посторонние импортированные библиотеки. Для новых пользователей предусмотрена короткая
вводная подсказка; её можно открыть повторно в настройках.

## Прокрутка, пресеты и сочетания

Кнопка ↻ находится справа снизу. Долгое нажатие позволяет перетащить её; положение
сохраняется. В меню `⋮` есть возврат кнопки в правый нижний угол; средства доступности
также позволяют разместить её слева.

`⋮ → Пресеты барабанов`: семь встроенных шаблонов с описаниями и сохранение своих
наборов категорий. Пресет задаёт порядок и типы барабанов; текущие источники, набор
тегов и фильтр продолжают действовать. Отдельный пользовательский набор тегов хранит
снимки выбранных тегов и игр. ↶ отменяет применение пресета.

Встроенные шаблоны проверяются во всех пяти режимах с полным каталогом, каталогом
публичной сборки и авторскими тегами. «Теги GameReel» закрывают категории, которых
может не быть у отдельных игровых источников. При пользовательском ограничении
источников или тегов пустые категории допустимы; творческие твисты добавляются
к фильтру только при явном включении соответствующей опции.
[Аудит пресетов и тегов](docs/PRESET_AUDIT.md).

После остановки появляются подходящие синергии из десяти авторских правил и до двух
редких пар механик. Алиасы сопоставляются явно, одинаковые механики не удваивают комбо.
Редкость считается только по выбранным наборам, по играм с двумя и более распознанными
механиками; одноимённые записи объединяются. Для показа нужно минимум 20 таких игр и
минимум три примера каждой механики. Это ограниченная статистика неполной разметки,
а не оценка уникальности или качества будущей игры.

## Структура

- `core` — модели, генерация, операции с рабочим пространством и контракт хранения.
- `app/shared` — общие экраны, ViewModel, импорт и реализации хранилища.
- `app/androidApp`, `desktopApp`, `webApp`, `iosApp` — платформенные точки входа.
- `tools/library_sources` — исходные генераторы библиотек.
- `tools/build_bundled_libraries.py` — сборка встроенных JSON из локальных снимков.

Правила оформления и расположения файлов: [CODE_STYLE.md](docs/CODE_STYLE.md).

## Локализация

Строки интерфейса лежат в `app/shared/src/commonMain/composeResources/values/strings.xml`
(английский по умолчанию) и каталогах `values-ru`, `values-es`, `values-fr`, `values-de`.
Язык выбирается в настройках и применяется без перезапуска. Описания из библиотек без
перевода остаются на исходном языке. Совпадение ключей и параметров строк проверяет
`python tools/check_localizations.py`. `core` не содержит текстов UI: ошибки типизированы
(`EditorError`, `ImportWarning`), а подписи enum маппятся в `ui/presentation/TagPresentation.kt`.

## Проверка и запуск

```powershell
.\gradlew.bat :core:jvmTest :app:shared:jvmTest :app:androidApp:assembleDebug
.\gradlew.bat :app:desktopApp:run
.\gradlew.bat :app:webApp:wasmJsBrowserDevelopmentRun
```

Для JS: `:app:webApp:jsBrowserDevelopmentRun`. iOS запускается из `app/iosApp` в Xcode на macOS.

APK: `app/androidApp/build/outputs/apk/debug/androidApp-debug.apk`.

## Обновление встроенных наборов

При наличии `tools/library_sources/*/data/games_1000.json`:

```powershell
python tools/build_bundled_libraries.py
```

Затем `python tools/fetch_store_images.py` подтягивает актуальные картинки: header из Steam и иконки Google Play
(кэш в `tools/library_sources/store_images.json`, `--refresh` перезапрашивает всё), ищет игры-референсы,
которых нет в наборах, сначала в Steam, потом в Google Play (`ref_*.webp` + `ReferenceArt.kt`; `--retry-missing` повторяет
ненайденные, в том числе игры наборов со снятыми страницами — их ищет по названию), и поднимает версию наборов до 7. Запускать после каждой сборки.

Сборка применяет правила v5 без загрузки новых рейтингов. Google Play основан на историческом
срезе июня 2021; разметка эвристическая. Новые метаданные магазина автоматически не запрашиваются.
