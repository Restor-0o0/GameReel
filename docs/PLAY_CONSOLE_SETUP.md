# Play Console: ответы для настройки GameReel

Приложение: GameReel, пакет `com.restor.gamereel`, версия 1.3.2 (versionCode 7).
Бесплатное, без рекламы, без покупок, без аккаунтов. Интернет нужен только для каталога
игровых пакетов (GitHub); личные данные не отправляются. Чужих картинок игр в сборке нет.
Нет аналитики и SDK сбора данных. Все данные пользователя хранятся только на устройстве.

## Возрастные ограничения (анкета IARC)

- Email: ваш адрес для связи.
- Категория: «Все остальные типы приложений» (не игра, не соцсеть).
- Насилие, сексуальный контент, нецензурная лексика, наркотики, алкоголь, табак: Нет.
- Азартные игры, ставки, имитация азартных игр: Нет. Барабаны это генератор идей
  и рандомайзер без ставок, выигрышей и денег.
- Общение пользователей, обмен контентом между пользователями: Нет.
  Ссылка «поделиться идеей» это обычная ссылка, без сервера и чата.
- Передача местоположения: Нет. Покупки цифровых товаров: Нет.
- Ожидаемый результат: самый низкий рейтинг (3+ / PEGI 3 / Everyone).

## Безопасность данных

1. Общие сведения: «Далее».
2. Собирает или передаёт приложение пользовательские данные обязательных типов? **Да**
   (из-за кнопки «Предложить в каталог» в редакторе пакетов).
3. Шифруются ли данные при передаче? **Да** (только HTTPS).
4. Можно ли запросить удаление данных? **Да**: напишите на почту разработчика, и пак будет
   удалён с Диска разработчика (и из каталога, если его уже приняли).
5. Типы данных: отметить только раздел «Сообщения» → **«Другой пользовательский контент»**
   (пак и необязательный комментарий). Остальное не отмечать.
6. Для «Другого пользовательского контента»:
   - собираются: **Да**; передаются третьим лицам: **Нет** (Google Apps Script и Google Диск
     работают как обработчики от имени разработчика, на GitHub пак попадает только после
     ручной проверки);
   - обрабатываются эфемерно: **Нет**;
   - обязательно ли: **Нет, пользователь может выбрать** (отправка только по кнопке);
   - цель: **Функциональность приложения**.
7. Каталог пакетов качается напрямую с GitHub; в этих
   запросах нет пользовательских данных, их декларировать не нужно.
8. В анкете IARC ответ «Обмен контентом между пользователями: Нет» остаётся: паки проходят
   ручную проверку, прямого общения между пользователями нет.

## Настройки магазина (Store settings)

- Тип: Приложение. Категория: **Инструменты** (Tools).
- Теги: можно не выбирать или «Разработка», «Генератор».
- Контакты: email обязателен, сайт можно `https://github.com/Restor-0o0/GameReel`.

## Выпуск

- Тестирование → Внутреннее тестирование (или Закрытое) → Создать выпуск.
- Play App Signing: принять (подписывает Google).
- Файл: `app/androidApp/build/play/outputs/bundle/play/androidApp-play.aab`.
- Название выпуска подставится само (1.3.2). Примечания:
  `Каталог игровых пакетов-рандомайзеров с установкой в одно касание, нарисованные иконки тегов.`
- Для нового личного аккаунта перед продакшеном нужен закрытый тест:
  12+ тестировщиков на 14 дней подряд.
