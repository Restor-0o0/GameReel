# Пресеты, фильтры и покрытие тегов

Проверка от 15 октября 2026 года охватывает все шесть встроенных библиотек:
22 068 экземпляров тегов после объединения повторов внутри одной игры.
Структурный аудит не нашёл пустых имён, неизвестных категорий, повреждённых символов,
технических заглушек или повторных идентификаторов в авторских наборах.
Это проверка структуры и покрытия; новая сверка всех игровых метаданных с магазинами
не проводилась.

## Исправления

- Поиск `mmo` внутри слова ошибочно исключал `ammo scarcity`, `summoning` и
  `summon placement`. Встроенные режимы теперь сопоставляют слова и фразы,
  нормализуют дефисы и другие разделители, распознают MMORPG и явные групповые действия.
- Пустой список активных источников в свободном режиме трактовался движком как
  отсутствие ограничений. Редактор теперь всегда передаёт конкретный пул тегов.
- Полностью отфильтрованный пул оставлял предыдущие значения случайных барабанов.
  Теперь они очищаются; заморозка, закрепление и прокрутка одного барабана соблюдаются.
  Действие можно отменить.
- Пользовательский фильтр с фиксированными источниками неявно получал авторские
  твисты. Дополнение теперь включается только опцией творческих твистов и не
  расширяет пользовательский снимок набора тегов.

## Каталог

В авторском каталоге отсутствовал «Масштаб», используемый встроенной «Подачей».
Steam Broad мог скрывать этот пробел; в публичной сборке этого источника нет.
Добавлены 8 тегов масштаба, 8 особенностей платформы и управления, 6 моделей оплаты.
Теперь каталог содержит 1461 тег в 18 категориях. «Прочее» оставлено для
неклассифицированных метаданных источников и не используется встроенными шаблонами.

Исходные 1439 тегов, их имена и описания сохранены. Новые записи — редакторские
варианты проектирования; они не утверждают наличие особенностей у конкретных игр.
Для них есть описания и короткие подписи; игры-референсы не выдумывались.
Версия библиотеки увеличена до 10, чтобы существующие установки получили обновление.

Источник дополнений: `tools/library_sources/review/curated_additions.json`.
Пересобрать только авторский каталог и его справочники без изменения игровых снимков:

```powershell
python tools/build_bundled_libraries.py --curated-only
```

## Шаблоны

| Пресет | Категории и задача |
| --- | --- |
| Геймджем | Основная механика, структура сессии, визуальный стиль, твист |
| Маленький прототип | Основная механика, взаимодействие, давление, масштаб |
| Эксперимент | Основная механика, взаимодействие, структура, мир, твист |
| Мир и окружение | Мир, локация, окружение, тема |
| Игровой процесс | Основная и дополнительная механики, структура, давление, прогрессия |
| Подача | Камера, визуальный стиль, тема, масштаб |
| Совместная игра | Основная механика, формат игроков, взаимодействие, структура |

Шаблон задаёт категории, а режим ограничивает пул. Например, шаблон «Геймджем»
можно сочетать с режимом «Геймджем» для ограничения масштаба. Эти инструменты не
оценивают автоматически совместимость каждой пары механик или стоимость разработки.
Описание задачи каждого шаблона доступно на пяти языках интерфейса.

## Повторная проверка

```powershell
python tools/audit_bundled_tags.py
python tools/check_localizations.py
.\gradlew.bat :core:jvmTest :app:shared:jvmTest :app:androidApp:assembleDebug
```

Структурный отчёт: `build/preset-audit/tag-audit.json`.
`PresetCompatibilityTest` перебирает семь пресетов и стартовые барабаны во всех пяти
режимах, с полным каталогом, публичным каталогом, только авторским каталогом и
авторскими тегами вместе с каждым отдельным источником. Для каждой комбинации
проверяются наличие минимум двух разных тегов на категорию, пять прокруток,
соблюдение источников и режима. Пользовательские наборы остаются строгими:
отсутствующие категории не заполняются посторонними тегами.
