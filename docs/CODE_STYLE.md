# Оформление и организация кода

Базовые настройки редактора находятся в корневом `.editorconfig`: UTF-8,
четыре пробела для Kotlin, длина строки до 100 символов, без пробелов в конце строк.
Длинные строковые литералы не нужно разрывать ради ограничения длины строки.

Между функциями и самостоятельными этапами работы оставляем одну пустую строку.
Внутри функции отделяем подготовку данных, проверку условий, изменение состояния
и возврат результата. В Compose отделяем состояние и вычисления от разметки,
а основное содержимое — от диалогов. Связанные короткие объявления можно оставлять вместе.
Несколько действий обработчика записываем на отдельных строках, без `;`.

Большие вызовы и вложенные компоненты раскрываем на несколько строк.
Короткие обработчики вроде `onClick = { onClose() }` не требуют отдельной функции.
Самостоятельный диалог или вспомогательный контракт можно вынести в соседний файл,
сохранив пакет и поместив его рядом с использующим кодом.

## Расположение файлов

- `core` содержит модели, генератор и операции над состоянием без зависимостей на UI и БД.
- `app/shared/feature` группирует интерфейс по экранам; данные и действия приходят параметрами.
- `app/shared/presentation` связывает операции, сохранение и состояние интерфейса.
- `app/shared/data` содержит импорт, встроенные библиотеки и хранение.
- Платформенные точки входа находятся в `app/*App`, реализации хранилища — в платформенных source sets.
- `tools/library_sources` хранит снимки данных и инструменты их подготовки; `docs` — документацию.

Пустой `server` не подключён к Gradle. Подключать модуль стоит вместе с его реализацией.
Каталоги `build`, `.gradle`, `.kotlin` и `__pycache__` являются рабочими артефактами,
а не исходниками. Архивы исходных наборов не переносим без проверки использующих их инструментов.

## Форматирование

Для Kotlin и Gradle Kotlin DSL использован [ktfmt](https://github.com/Kotlin/ktfmt)
0.64 со стилем `--kotlinlang-style` и сохранением импортов
(`--do-not-remove-unused-imports`). Команда для повторного запуска с локальным JAR:

```powershell
.\tools\format_kotlin.ps1 -FormatterJar C:\tools\ktfmt-0.64-with-dependencies.jar
.\tools\format_kotlin.ps1 -FormatterJar C:\tools\ktfmt-0.64-with-dependencies.jar -Check
```

Форматтер не заменяет ручную расстановку смысловых пустых строк.
Правила `.editorconfig` также помогают сохранять оформление в Android Studio.

Из общего форматирования исключены `CuratedDescriptions.kt`, `CuratedReferences.kt`
и `ReferenceArt.kt`: их создают инструменты сборки библиотек и загрузки изображений.
Правки данных нужно делать в источниках и генераторах.
`TagShortNames.kt` содержит большой строковый справочник и также исключён,
чтобы массовое форматирование не меняло его табличное представление.
