# Проверка плавности вращения

Проверка выполнена на подключённом Android-телефоне RMX3760.
Для каждого замера сбрасывалась статистика `dumpsys gfxinfo`, затем выполнялись
четыре нажатия на рычаг с интервалом около 2,1 секунды.
Измерение включает начало и завершение анимации, а также появление карточек результата.

| Вариант | Кадров | Проблемных кадров | p95 | p99 |
| --- | ---: | ---: | ---: | ---: |
| Исходная установленная сборка | 322 | 8,70% | 150 мс | 400 мс |
| Canvas, debug, первый замер | 321 | 16,82% | 61 мс | 300 мс |
| Canvas, debug, после прогрева | 290 | 17,59% | 46 мс | 200 мс |
| Canvas, release | 298 | 4,03% | 26 мс | 69 мс |
| Canvas + поочерёдная остановка и звук, release | 504 | 3,37% | 29 мс | 57 мс |

Данные — короткие локальные замеры, не гарантия постоянных 60 FPS.
В debug длительность тяжёлых кадров снизилась, но доля кадров с пропуском срока
не улучшилась. Итоговый результат release включает и изменения кода, и оптимизацию
сборки: приписывать всю разницу одному исправлению нельзя. Наборы случайных
результатов и состояние кэшей между замерами отличаются.

## Изменения

- Графические барабаны рисуют три видимых элемента через один Canvas на барабан.
- Текст и изображения больше не заменяются в Compose-дереве при каждом шаге прокрутки.
- Текстовые барабаны используют заранее созданную ленту и перемещение графических слоёв.
- Декодирование изображений перенесено из UI-корутины на `Dispatchers.Default`;
  повторные загрузки объединяются через кэш и блокировку.

## Поочерёдная остановка и звук

`SpinTimeline` запускает все незаблокированные барабаны одновременно. Первый
останавливается через 480 мс (быстро) или 1100 мс (обычно), следующие — с шагом
125 мс в порядке на экране. При перебросе одного барабана дополнительной задержки нет.
`SpinMotion` использует один линейный таймер; замедление вычисляется для каждого
барабана отдельно. Новый запуск отменяет предыдущую анимацию и её звуковые события.

`SpinSoundTracker` сопоставляет щелчки с переходами между значениями. Совпадающие
щелчки объединяются, обычные звучат не чаще раза в 30 мс; остановки имеют отдельный
звук. Пропущенный кадр не запускает очередь пропущенных щелчков. На Android короткие
семплы заранее загружены в SoundPool. Исходные звуки генерирует
`tools/generate_slot_sounds.py`; внешние записи не используются.

Переключатель «Звуки слот-машины» хранится в Preferences. В фоне, вне генератора
и при выключенной анимации щелчки не запускаются. Браузер разрешает звук после
первого действия пользователя. Последняя строка таблицы — проверка со звуком:
три полных вращения и быстрый повторный запуск на том же устройстве. Это отдельный
короткий замер с другими случайными результатами, а не строгое сравнение вариантов.

## Повторная проверка

```powershell
.\gradlew.bat :app:androidApp:assembleRelease
adb install -r app/androidApp/build/outputs/apk/release/androidApp-release.apk
adb shell am start -n com.restor.gamereel/.MainActivity
adb shell dumpsys gfxinfo com.restor.gamereel reset
# Выполнить несколько вращений после загрузки приложения.
adb shell dumpsys gfxinfo com.restor.gamereel framestats
```

Сравнивать производительность следует на одном устройстве и в одинаковом режиме
сборки. Текущая локальная release-конфигурация использует debug-ключ подписи.
APK для публикации требует отдельной настройки подписи.
