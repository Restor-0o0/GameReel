# Релиз-кандидат GameReel 1.2.0 (versionCode 4)

## Две комплектации и проверочный APK

| Артефакт | Содержимое | Подпись / назначение |
| --- | --- | --- |
| Local release APK | Все наборы и существующие обложки | Прежний debug key; локальное обновление, не для магазина |
| Preview APK | Редакторские теги и itch.io, без обложек | Debug key; отдельный `com.restor.gamereel.preview`, можно поставить рядом |
| Play AAB | То же содержимое, что Preview | Upload key из окружения; без ключа неподписанный кандидат |

Команды и пути: [PLAY_BUILD.md](PLAY_BUILD.md).

Публичная конфигурация физически исключает 2809 файлов обложек и три исторических
каталога Steam / Google Play, условия повторного распространения которых не установлены.
Остаются 1439 редакторских тегов и 28 игр / 120 тегов itch.io с оригинальными краткими
аннотациями. Источники — `tools/library_sources/itch_selected/provenance.json`.
Названия и ссылки используются справочно; это не разрешение на чужую графику.
Импорт пользовательских JSON не отключён; ответственность за публикуемые пользователем
материалы и дальнейшее распространение требует отдельной оценки.

Звуки синтезированы `tools/generate_slot_sounds.py`; чужие аудиозаписи не используются.
Адаптивная иконка создана из геометрических фигур в Android XML. Системные emoji
отрисовываются платформой. Лицензии AL2.0/LGPL2.1 больше не вырезаются упаковщиком.
Полноту уведомлений всех транзитивных зависимостей ещё следует проверить перед публикацией.

## Выполненные проверки

- 20 тестов core и 52 теста shared в локальной конфигурации — без ошибок.
- Все 52 теста shared также прошли с публичным каталогом.
- Preview установлен рядом с прежним приложением: запуск, прокрутка и список наборов проверены.
- В публичных APK/AAB нет файлов обложек, присутствуют только `curated.json` и `itch_selected.json`.
- ELF LOAD alignment всех четырёх ABI — 16384; Preview APK прошёл `zipalign -c -P 16 4`.
- Проверочный телефон использует страницы 4096 байт; runtime-проверка 16 KB ещё не выполнена.
- Play AAB не подписан: upload key не предоставлен. Отправка в Console не выполнялась.
