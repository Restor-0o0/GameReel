# Проверка релиза и план доработок

Проверено 27 сентября 2026. Это технический аудит и оценка рисков по опубликованным
правилам, а не юридическое заключение или гарантия прохождения модерации.
Обновление: реализованы плавающая кнопка с сохранением позиции, пресеты с выбором
источников и отменой, десять правил синергии, редкие пары, начальная подборка itch.io
(6 игр / 25 тегов), отдельная Play-сборка без встроенного арта и экран информации
о данных. Инструкции — в [PLAY_BUILD.md](PLAY_BUILD.md). Описания ниже сохраняют
основания решений и ограничения; глобальная уникальность идей не заявляется.

## Можно ли публиковать текущую версию

Сам генератор игровых идей можно готовить к Google Play. Текущую сборку нельзя
считать готовой: не подтверждены права на встроенные изображения, используется
debug-подпись, не подготовлена политика конфиденциальности.

В `composeResources/files/art` и проверенном release APK находятся 2809 изображений.
`tools/fetch_store_images.py` загружает Steam header и Google Play icons, уменьшает
их и сохраняет в WebP. Это распространение копий внутри приложения. В просмотренных
файлах проекта не найден реестр лицензий или разрешений на эти изображения.
Это не доказывает отсутствие разрешений у владельца проекта вне репозитория.

Google прямо перечисляет игровые обложки и рекламные изображения среди примеров
проблемного использования чужого контента без необходимых прав. Может потребоваться
документальное подтверждение разрешений. [Правила интеллектуальной собственности](https://support.google.com/googleplay/android-developer/answer/9888072?hl=en).

Ссылка на источник, подпись владельца, уменьшение картинки, бесплатность приложения
или загрузка картинки по URL вместо включения в APK сами по себе не дают лицензию.
Вопрос применения исключений из авторского права зависит от юрисдикции и конкретного
использования; полагаться на американский fair use как на универсальное разрешение
нельзя. [Объяснение fair use Copyright Office](https://copyright.gov/fair-use/).

Практический вариант для первого выпуска: оригинальные пиктограммы механик,
названия игр и ссылки как справочные примеры без впечатления официального партнёрства;
чужие изображения — только при подтверждённом основании использования. Если выбрать
такой вариант, изображения надо исключить из поставляемых ресурсов, а не просто
спрятать в интерфейсе. Для изображений, которые решено оставить, нужен реестр:
файл → автор/правообладатель → источник → текст/версия лицензии либо разрешение →
допустимое использование, коммерческое распространение, изменения и атрибуция.
Условия press kit и лицензии на код игры нельзя автоматически переносить на арт.

## Предлагаемый порядок доработок

### 1. Кнопка прокрутки

Material 3 FloatingActionButton внизу справа, над нижней навигацией, только на
генераторе. Вызывает существующий `actions.spin`; при всех заблокированных барабанах
недоступна. Добавить нижний отступ списку, чтобы кнопка не закрывала последний результат.
Перемещение — долгим нажатием и перетаскиванием, обычное касание крутит. Ограничивать
позицию видимой областью с учётом системных отступов, сохранять относительное положение
для разных размеров экрана, предусмотреть сброс и доступное размещение слева/справа.

### 2. Пресеты барабанов и наборов

Пресет сохраняет имя, порядок/категории барабанов, закреплённые значения и выбор
библиотек. Сохранённая идея остаётся результатом генерации, пресет — настройкой генератора.
Встроенные примеры: «Джем», «Маленький прототип», «Эксперимент»; плюс пользовательские.
Применение должно быть атомарным, отменяемым и переживать перезапуск.

«Фикс наборов» пока неоднозначен. Если это фиксированный выбор данных — хранить
явный список включённых libraryId в пресете: новые библиотеки не должны автоматически
попадать в него. Если нужна воспроизводимость при обновлениях, одних ID недостаточно:
нужны версия/хеш и доступный снимок набора. При отсутствии библиотеки показывать это
пользователю, без незаметной подмены источника.

Если речь об исправлении данных — отдельно проверить дубликаты игр, синонимы тегов,
категории, описания и источники. Google Play использует срез октября 2026 по текущим установкам,
а часть разметки эвристическая; её нельзя выдавать за полностью проверенную.

### 3. Сочетания тегов после вращения

Разделить два сигнала:

- **Синергия**: авторское правило из двух-трёх механик, название и объяснение,
  например «ограниченные ресурсы + крафт → выбор между немедленной выгодой и запасом».
  Это гипотеза игрового дизайна, не гарантия успешной игры.
- **Необычное сочетание**: редко встречается либо не найдено в конкретном наборе.
  Показывать границы вывода: «Не найдено среди N размеченных игр», а не «Никто такого
  не делал». Отсутствующие теги в неполной разметке не доказывают новизну.

Хранить правила отдельно от UI, по каноническим ID механик с таблицей соответствий
для разных библиотек. Матчинг — чистая функция в core, без привязки к тексту перевода.
Показывать лучшие несколько совпадений после остановки последнего барабана; подсвечивать
участвующие теги и объяснять связь. Повтор одного тега не должен искусственно усиливать
комбо. Для статистики дедуплицировать одни и те же игры между площадками, сохранять
версию корпуса и учитывать полноту разметки. Подсчёты не выполнять каждый кадр анимации.

### 4. Набор itch.io

Начать с небольшой проверенной подборки, сохранять URL игры, автора, дату проверки,
основание разметки и условия использования данных/арта. Не выводить механику только
из популярности или магазинной категории; предусмотреть авторский импорт и проверку.
Исключать дубли существующих игр по соответствиям площадок.

Наличие игры на itch.io не означает свободную лицензию на её обложку. Условия дают
платформе и пользователям права в рамках сервиса; из них нельзя выводить общее разрешение
упаковать чужой арт в сторонний генератор. Официальный API в основном ориентирован
на аккаунт и его проекты, поэтому стратегию получения каталога нужно выбирать отдельно,
без предположения о наличии полного публичного каталожного API.
[Условия itch.io](https://itch.io/docs/legal/terms),
[API](https://itch.io/docs/api/overview), [методы](https://itch.io/docs/api/serverside).

## Границы проверки

Не проводилась юридическая проверка каждого из 2809 изображений и каждого исходного
датасета; разрешения у правообладателей не запрашивались. Решение модерации предсказать
нельзя. Если важно сохранить именно чужие обложки, понадобится проверка оснований
использования с юристом по авторскому праву для целевых стран распространения.
Исходные картинки сохранены в проекте для локальной версии; Play-конфигурация исключает
их из пакета. Публикация, получение лицензий и заполнение Play Console не выполнялись.
