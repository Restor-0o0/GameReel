# GameReel — проект политики конфиденциальности

Опубликованная версия: [site/privacy/index.html](../site/privacy/index.html),
URL <https://restor-0o0.github.io/GameReel/privacy/>. Контакт: GitHub Issues репозитория.
Ниже исходный проект от 27 сентября 2026 года.

GameReel — локальный генератор игровых идей. Приложение хранит идеи, заметки,
пресеты, настройки и импортированные библиотеки на устройстве пользователя.
Регистрация не требуется. Собственного сервера для передачи этих данных,
аналитических и рекламных SDK в проверенной версии нет.

Android-приложение не запрашивает INTERNET. Импорт читает файл, выбранный через
системный диалог. Внешние ссылки открывает браузер; на целевых сайтах действуют
их собственные политики обработки данных.

Android может включать локальные данные приложения в системные резервные копии
в зависимости от настроек устройства. Их обработка регулируется условиями
соответствующего системного сервиса. После восстановления резервной копии ранее
сохранённые данные могут снова появиться.

Идеи и пресеты можно удалить внутри приложения. Полностью удалить локальные данные
Android можно через системные настройки приложения. Данные сохраняются до удаления
пользователем/системой. Для веб-версии применяется очистка данных сайта в браузере;
хостинг сайта может вести обычные журналы HTTP-запросов. Если публикуется веб-версия,
дополнить сведения её фактическим хостингом и сроками хранения журналов.

При добавлении аналитики, рекламы, сетевого импорта, синхронизации или учётных записей
повторно проверить текст и Data safety до выпуска обновления.

Основание требований: [Google Play User Data](https://support.google.com/googleplay/android-developer/answer/10144311?hl=en).
