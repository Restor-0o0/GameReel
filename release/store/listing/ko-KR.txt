Название (title):
GameReel

Краткое описание (short description, до 80 символов):
게임 아이디어 생성: 메커닉, 배경, 조합, 릴 프리셋.

Полное описание (full description):
다음 게임의 출발점을 찾아 보세요. 릴을 돌려 메커닉, 비주얼 스타일, 제약, 배경을 조합합니다. 마음에 드는 요소는 고정하고 나머지는 다시 돌리세요.

• 설명이 담긴 태그 라이브러리와 엄선한 참고 게임.
• 원하는 대로 바꾸는 릴과 저장된 프리셋.
• 선택한 라이브러리 안에서 잘 맞는 메커닉과 드문 조합 추천.
• 오늘의 아이디어: 하루 하나, 모두에게 같은 조합.
• 아이디어를 링크로 친구나 팀과 공유.
• 프로토타입, 게임잼, 출시 상태와 결과 링크가 있는 아이디어·메모 저장.
• 릴을 랜덤 뽑기로 바꾸는 게임 팩. 예: Dota 2 영웅, 아이템, 특성.
• 나만의 JSON 라이브러리와 프리셋 가져오기, GitHub 커뮤니티 카탈로그.
• 14개 언어, 애니메이션과 사운드 설정.

핵심 기능은 오프라인에서 계정 없이 작동합니다. 출처 링크는 브라우저에서 열립니다.
희귀도는 선택한 라이브러리 기준이며 아이디어의 독창성을 보장하지 않습니다.
GameReel은 독립 도구이며 언급된 게임, 퍼블리셔, 스토어와 제휴 관계가 없습니다.
