# Steam Top-1000 Idea Generator Seed Pack

Версия базы на 1000 игр для генератора игровых идей.

## Что изменилось относительно версии на 100 игр

Теперь база не ограничивается инди. Используется публичный CSV на 1000 Steam-игр с AppID, жанром, Steam-тегами, отзывами и оценкой владельцев. Скрипт автоматически превращает Steam-теги в атомы генератора: кор-механики, дополнительные механики, камера, тип графики, режим игроков и грубая оценка production scope.

Это специально сделано как широкая библиотека референсов: AAA здесь тоже полезны, потому что генератор может взять из них одну механику или визуальный принцип, не пытаясь повторять весь масштаб проекта.

## Быстрый старт Windows

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\build_all.ps1
```

Команда:
1. скачает исходный список 1000 игр;
2. создаст `data/games_1000.json` и `data/games_1000.csv`;
3. создаст барабаны в `data/reels_from_1000.json`;
4. сформирует `data/images_manifest.csv`;
5. скачает Steam header-картинки в `images/`.

Если картинки не нужны сразу:

```powershell
python .\scripts\build_top1000.py
```

## Главные файлы

- `docs/IDEA_GENERATOR_SPEC.md` — спецификация приложения-«однорукого бандита».
- `docs/TOP1000_DATASET.md` — как устроена база 1000 игр.
- `scripts/build_top1000.py` — сборщик и классификатор.
- `scripts/download_images.py` — загрузчик 1000 Steam header images.
- `data/games_1000.json` — появится после запуска сборщика.
- `data/games_1000.csv` — табличная версия.
- `data/reels_from_1000.json` — автоматически собранные барабаны.


## Дополнительный режим: Reference Spin

В спецификацию добавлен режим `Reference Spin`: генератор выбирает 2–3 игры из Top-1000 и отдельно крутит, **что именно** взять из каждой — кор, доп. механику, структуру, прогрессию, давление, графику, камеру, сеттинг или характер взаимодействия.

Для каждой карточки есть два независимых замка: `Freeze game` и `Freeze aspect`. После удачной комбинации её можно разложить обратно по обычным барабанам через `Extract to reels`. Также описано anti-copy правило, которое штрафует попытку взять слишком много аспектов из одной игры.

## Почему картинки скачиваются отдельным скриптом

Не стоит вшивать 1000 чужих Steam promotional images прямо в распространяемый архив. Гораздо удобнее хранить AppID и URL и локально подтягивать headers с CDN Steam. Это также позволяет обновлять набор и не раздувать архив на сотни мегабайт.

## Pinned tags — безусловное добавление

В спецификацию добавлен ручной `+ Pin`: из карточки любой игры можно взять конкретный `CORE`, механику, структуру, графику, камеру, сеттинг или обычный Steam-тег и **без рандома** добавить его в концепт.

Такой элемент сразу появляется отдельным замороженным барабаном в группе `Pinned` слева. Обычные Spin/Reroll его не меняют; генератор докручивает остальные строки вокруг уже выбранных пользователем условий. `Unlock all` не снимает Pin — для этого используются явные `Unpin` / `Remove`.

Поддерживается и пакетный сценарий: открыть игру, отметить несколько нужных её аспектов и нажать `Add selected as pinned reels`.


## Tag enrichment v4

В этой версии разметка расширена: кроме CORE/secondary добавлены structure, progression, pressure, interaction, setting, theme, visual, camera и players. Общие теги больше не получают повышенный random-weight только из-за частоты.

Если ты уже собрал `data/games_1000.json`, не нужно заново скачивать список игр:

```powershell
python .\scripts\enrich_existing.py
```

Подробности: `docs/TAG_ENRICHMENT.md`.
