# Подключение Google Play как отдельной библиотеки

Рекомендуемый переключатель источника:

- Steam — current / broad
- Steam — all-time owners
- Google Play — install leaders
- All libraries

Каждая запись содержит `library`, поэтому генератор может смешивать источники или ограничивать конкретный Spin.

Для Reference Spin у Google Play карточка игры должна показывать:

- изображение;
- категорию;
- installs/rating count;
- monetization atoms;
- кнопки `+ Pin category`, `+ Pin mechanic`, `+ Pin monetization`, `+ Pin visual from this game`.

`Pin` создаёт слева безусловный замороженный барабан так же, как описано в основной спецификации.
