# Steam All-Time Top 1000 — методика

Эта библиотека специально отделена от предыдущего набора `Top 1000 Steam Games (2024–2026)`.

## Что означает «all-time» здесь

Используется открытый SteamSpy API: `request=all&page=0`. По документации SteamSpy, `all` возвращает 1000 игр на страницу и сортирует их по числу владельцев. Поэтому этот набор — **топ-1000 Steam по накопленной аудитории/владельцам**, а не текущие продажи и не релизы последних лет.

Это не идентично рейтингу Steam250. Steam250 ведёт Top 1000 и исторические позиции, но публичная страница показывает первые 250, а продолжение 251–1000 находится в Club 250.

Для генератора идей рейтинг нужен прежде всего как фильтр на широко известные/массовые игры, поэтому owners-based all-time срез подходит лучше, чем смешивание текущих новинок.

## Что генерируется

- `data/games_1000.json`
- `data/games_1000.csv`
- `data/reels_from_1000.json`
- `data/images_manifest.csv`
- `images/*.jpg`

Steam community tags превращаются в атомы механик. Оригинальные теги сохраняются полностью, чтобы их можно было безусловно Pin-ить в левую замороженную область генератора.
